# Migration notes

The package moved from a single-file writer to a small runtime with explicit
validation and a verification fixture.

## From the legacy MIDIFile

The old `MIDIFile` class wrote absolute-tick events into a Type 1 file. The new
runtime does the same but adds:

- explicit SHA-256 and structural validation
- a canonical 4-track verification fixture
- a CLI
- plugin knowledge overlays for AI-assisted use

## From earlier plugin versions

The plugin overlay now expects the runtime to be importable as `ai_midi_io`.
The verification fixture is generated by the runtime rather than checked in as
a binary when possible.

See `docs/PLUGIN.md` for the current plugin layout.
