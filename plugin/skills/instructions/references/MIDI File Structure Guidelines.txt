MIDI File Structure Guidelines

### 1. MIDI File Header and Tracks:
• Use the MIDI file header (b'MThd') and track header (b'MTrk') to begin each file and track.
• Support multi-track MIDI files, with correct track length and tempo settings.
### 2. Meta Events and Note Events:
• Set the tempo using MetaMessages for tempo changes, and define note events using Note On (0x9x) and Note Off (0x8x).
• Ensure timing (delta times) is properly encoded using variable-length encoding.
