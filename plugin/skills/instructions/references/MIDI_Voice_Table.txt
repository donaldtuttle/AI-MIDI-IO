### **MIDI Voice Table**

The **MIDI Voice Table**, typically referring to the **General MIDI (GM) Instrument Patch List**, is a standardized set of 128 instrument sounds that can be selected using **Program Change** messages. Each instrument is assigned a number, and MIDI devices use this list to ensure that the same Program Change message will result in the same instrument sound across different devices.

This voice table is critical for consistency when transferring MIDI files between different systems, as it ensures that a piano sound on one device will be a piano sound on another.

### **How MIDI Voices Are Selected and Interpreted**

- **Program Change Messages**: 
   - The **Program Change** message instructs the MIDI device to switch to a specific instrument. Program Change messages are sent on a particular channel and include a single data byte that specifies the desired instrument number (from 0 to 127). 
   - Example: `C0 00` switches to Program 0, which is the **Acoustic Grand Piano**.
