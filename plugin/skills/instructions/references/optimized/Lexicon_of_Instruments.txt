Comprehensive Knowledge File: MIDI Controllers
1. Overview of MIDI Controllers
MIDI controllers are devices used to send MIDI messages to other hardware or software (such as synthesizers, DAWs, or samplers).
They don't generate sound themselves but provide an interface to control various parameters of sound-generating devices.
MIDI controllers often include pads, sliders, rotary encoders, knobs, and buttons, each sending MIDI control messages to manipulate sound parameters like volume, pitch, and effects.

2. QuNeo 3D Pad Controller
2.1 General Overview:

The QuNeo is a pressure-sensitive, touch-sensitive controller with 16 square pads, sliders, rotary controls, and transport buttons.
It is often used for triggering samples, controlling virtual instruments, and manipulating sound parameters in a DAW or MIDI-capable device.
2.2 Key Features:

16 Pressure-Sensitive Pads:
Each pad can send velocity data (128 levels of pressure sensitivity).
X-Y Location tracking for each pad, allowing users to modulate parameters based on the position of their touch.
Horizontal and Vertical Sliders:
These sliders send continuous Control Change (CC) messages that can be assigned to modulate various sound parameters, such as filter sweeps, volume, or panning.
Rotary Controls:
Each rotary detects both pressure and rotation to control DAW or synth parameters like gain or effect levels.
Transport Controls:
Buttons for play, pause, record, and other common DAW commands.
2.3 MIDI Parameters:

Each pad, slider, and rotary control sends MIDI CC messages that can be assigned in your DAW or hardware.

Pads:

Velocity Sensitivity: 128 levels.
X and Y Axes: Pads send positional data as CC messages based on the X and Y positions.
Continuous Pressure: Pads can continuously transmit pressure levels while held, allowing for modulation over time.
Sliders:

Both horizontal and vertical sliders send continuous control (CC) messages.
Each slider can be assigned to control volume, filters, or any other MIDI-enabled parameter.
Rotaries:

Continuous rotary controls that detect direction and pressure.
MIDI CC messages from rotaries can be mapped to various software or hardware parameters for smooth adjustments.
Buttons:

Transport buttons send MIDI note or CC messages, typically used for controlling playback, stop, record, or automation controls in a DAW.
2.4 Assignable MIDI Parameters:

The QuNeo allows for custom MIDI mappings depending on the software or hardware setup.
You can reassign pads, sliders, and rotary controls to specific MIDI CC numbers in compatible software or DAWs.
Typical assignments include:

Filter cutoff and resonance (CC74 for filter cutoff, CC71 for resonance).

QuNeo supports multiple layers of control via bank switching, allowing users to map different CC messages to the same control depending on the active layer.
Each slider and pad can control different MIDI parameters across different layers, providing vast control options without switching between physical devices.
2.6 Integration with DAWs:

The QuNeo has presets for popular DAWs like Ableton Live, Logic Pro, and FL Studio, with pre-mapped functions for pads, sliders, and rotaries.
