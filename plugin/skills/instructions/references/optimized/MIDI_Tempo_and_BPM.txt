Let's cover **tempo** and **BPM (Beats Per Minute)** in the context of MIDI, specifically how tempo is handled in MIDI files and how you can manipulate tempo programmatically using Python. Tempo is a critical aspect of MIDI data, as it controls the timing of all events in a sequence.

---

### **Understanding Tempo in MIDI**

#### **1. What is Tempo in MIDI?**
- **Tempo** in MIDI refers to the speed at which the music is played, measured in **beats per minute (BPM)**. 
- MIDI uses **meta messages** to control the tempo. Specifically, a **Set Tempo** meta message (`FF 51 03`) sets the tempo for the entire track.

---

#### **2. How MIDI Tempo is Represented**

Tempo is encoded in MIDI files in **microseconds per quarter note** rather than directly in BPM. This is because the original MIDI standard aimed to provide fine control over timing.

**Formula for converting microseconds per quarter note to BPM**:
```plaintext
BPM = 60,000,000 / microseconds_per_quarter_note
```

For example, a tempo of 120 BPM is represented as:
```plaintext
60,000,000 / 120 = 500,000 microseconds per quarter note
```

- If you see a tempo message like `FF 51 03 07 A1 20` in a MIDI file, this means the tempo is 500,000 microseconds per quarter note, which corresponds to 120 BPM.

---

### **Manipulating Tempo in Python using `mido`**

#### **3. Reading and Changing Tempo in MIDI Files**

To read the tempo from a MIDI file or set a new tempo, we use `mido`'s support for **meta messages**. Below is an example of how to read and modify the tempo.

##### **Reading the Tempo from a MIDI File**

```python
import mido

# Open a MIDI file
mid = mido.MidiFile('example.mid')

# Iterate through tracks to find the Set Tempo meta message
for track in mid.tracks:
    for message in track:
        if message.type == 'set_tempo':
            tempo = message.tempo  # Tempo in microseconds per quarter note
            bpm = mido.tempo2bpm(tempo)
            print(f'Tempo: {tempo} microseconds per quarter note ({bpm} BPM)')
```

##### **Explanation**:
- **`set_tempo`**: Meta message that sets the tempo.
- **`message.tempo`**: This gives the tempo in microseconds per quarter note.
- **`mido.tempo2bpm(tempo)`**: Converts microseconds per quarter note to BPM.

---

##### **Changing the Tempo in a MIDI File**

You can change the tempo by writing a new `set_tempo` message into the MIDI file. Here's an example of setting a new tempo:

```python
from mido import MidiFile, MidiTrack, MetaMessage

# Open the MIDI file
mid = MidiFile('example.mid')

# Create a new track and set the tempo to 100 BPM
track = MidiTrack()
mid.tracks.append(track)

# Convert 100 BPM to microseconds per quarter note
new_tempo = mido.bpm2tempo(100)

# Add a Set Tempo message to the new track
track.append(MetaMessage('set_tempo', tempo=new_tempo))

# Save the new MIDI file
mid.save('example_with_new_tempo.mid')
```

##### **Explanation**:
- **`mido.bpm2tempo(100)`**: Converts 100 BPM to microseconds per quarter note.
- **`MetaMessage('set_tempo', tempo=new_tempo)`**: Creates a Set Tempo meta message with the new tempo.
- **`track.append()`**: Adds the tempo message to the track.

#### **4. Real-Time Tempo Manipulation (Live MIDI)**

When working with real-time MIDI (e.g., live performances or automated systems), you may want to adjust the tempo dynamically. Here's how to implement a basic tempo controller in Python that adjusts tempo in real-time:

```python
import mido
import time

# Open output port for real-time control
out_port = mido.open_output('MIDI Output Name')

# Define the base tempo in BPM (e.g., 120 BPM)
bpm = 120
tempo = mido.bpm2tempo(bpm)

# Function to send a tempo change message
def change_tempo(new_bpm):
    global tempo
    tempo = mido.bpm2tempo(new_bpm)
    tempo_message = MetaMessage('set_tempo', tempo=tempo)
    out_port.send(tempo_message)

# Example: Changing tempo in real-time
time.sleep(5)  # Wait for 5 seconds at the original tempo
change_tempo(140)  # Increase the tempo to 140 BPM
time.sleep(5)  # Play at the new tempo for 5 seconds
```

In this example:
- You start with a **base tempo** (120 BPM).
- After 5 seconds, the tempo changes to 140 BPM, and the new Set Tempo message is sent.

#### **5. Working with Tempo Maps**

In some musical compositions, the tempo is not constant and may change throughout the piece. MIDI files allow for **tempo maps**, where the tempo is adjusted at different points in time.

##### **Reading and Displaying the Tempo Map**

```python
import mido

# Load the MIDI file
mid = mido.MidiFile('example_with_tempo_changes.mid')

# Extract tempo changes from the file
tempo_changes = []
for track in mid.tracks:
    time_passed = 0
    for message in track:
        time_passed += message.time
        if message.type == 'set_tempo':
            bpm = mido.tempo2bpm(message.tempo)
            tempo_changes.append((time_passed, bpm))

# Display the tempo map
for change in tempo_changes:
    print(f'Time: {change[0]} ticks, Tempo: {change[1]} BPM')
```

##### **Explanation**:
- The script tracks all `set_tempo` messages and records the time (in ticks) at which the tempo changes.
- It then converts each `set_tempo` message into BPM and stores the data in a tempo map.

### **6. Practical BPM Considerations for Live and Sequenced Music**

#### **Live Performance**
- **MIDI Clock**: For live performances, MIDI often uses **MIDI Clock** messages to keep devices synchronized. These messages are sent 24 times per quarter note, ensuring that multiple devices (synthesizers, sequencers, drum machines) stay in time.
  - Example Clock Message: `F8` (timing clock).
- **Tempo Sync Across Devices**: Using MIDI Clock, you can ensure that multiple MIDI devices or DAWs stay synchronized to the same tempo, even if it changes during the performance.

#### **MIDI Sequencing**
- **Quantization**: When recording MIDI in a DAW, the tempo directly affects quantization. If you quantize a MIDI performance to 1/16th notes, the DAW aligns each note to the closest 1/16th beat according to the tempo.
- **Variable Tempo**: Some pieces of music, particularly classical or film scores, require tempo changes. These tempo changes can be programmed into MIDI sequences and interpreted by DAWs or hardware devices.
